项目理念

不是套一段人设，
而是让陪伴「有状态」

Ta 不只是给语言模型套一段固定人设，而是尝试让 Agent 在长期相处中保持连续、自然和有状态。

01
🪞

由你定义

名字、身份、性格、关系、表达方式、头像、声音与行为，全部可调。Ta 不预设它应该是谁。

02
🧠

人格而非关键词

人格特征结合当前话题动态表达，避免机械复读口头禅或持续围绕单一主题。

03
⏳

陪伴有时间感

Agent 有当天作息、当前活动与不同状态，不会始终以相同方式立即回复。

04
🔗

关系能够延续

聊天记忆、共同经历、关系阶段与情绪变化，都会成为后续交流的上下文。

05
🔒

数据留在本地

Agent 配置、聊天与记忆存储在设备中，API Key 在本地加密保存。

06
🗣️

声音是陪伴的一部分

Ta 不只为它生成文字，还能合成专属声音，让「他、她、它」真正开口说话。

语音特色

让 Agent
拥有自己的声音

语音能力围绕「让 Agent 拥有自己的声音」设计，覆盖从音色定制、情绪表达到播放体验的完整链路。

🎙️

音色复刻

上传一段参考音频样本，复刻出接近这套音色的声音，赋予 Agent 一个稳定、可辨识的嗓音。

voice clone
✨

音色设计

不提供样本，直接用文字描述想要的音色（「温柔的少女音」「沉稳的男声」），按描述生成声音。

voice design
🎧

预置音色

不提供样本、也不写描述时，使用内置的精品音色作为默认嗓音。你有多少种想法，Ta 就有多少种声音。

preset voice

界面预览

从首次配置到日常陪伴

下面按一次完整的使用流程，从首次配置到塑造 Agent，展示 Ta 的主要界面。

STEP 01 模型配置

填写 LLM 与 TTS 接入参数，支持保存多套配置、一键测试连通性并随时切换。
STEP 02 语音配置

为日常、开心、温柔三种情绪分别配置声音样本与语音参数，支持即时试听。
STEP 03 人格设定

定义身份背景、性格标签、说话习惯与示例对话，塑造 Agent 的表达内核。
STEP 04 配置草稿

对话式配置完成后生成完整草稿，可预览、可修改，确认后才会正式生效。
STEP 05 Agent 管理

集中管理头像、声音与行为设定，支持导入导出 .agent.zip 配置包。
STEP 06 日常聊天

类即时通信的对话体验，语音消息点击播放，多条回复逐条送达。
快速上手

四步，塑造你的 Ta

01

配置模型

在模型配置页填写 LLM 与 TTS 的 Base URL、API Key 与模型，点击「测试」做真实连接诊断。

02

开启后台权限

按提示开启通知权限、关闭电池优化、允许后台运行，保证 Agent 能稳定在后台生活作息。

03

对话式创建

进入聊天页输入 /config，选择对话式自定义、偶像参考或动漫人物参考，逐步描述想要的形象。

04

确认并开始陪伴

点击「完成并预览」查看配置草稿，确认无误后点击「确认应用」正式保存。之后在记忆、关系和作息中逐渐形成连续的陪伴体验。
