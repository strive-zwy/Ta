项目理念

不是套一段人设，
而是让陪伴「有状态」

Ta 不只是给语言模型套一段固定人设，而是让 Agent 在长期相处中保持连续、自然和有状态。

01

对话式创建

不填表单、不写配置。像聊天一样说出你的想象，Ta 通过多轮对话理解意图，生成可预览、可修改的草稿，确认后才正式生效。

02

专属声音

上传一段音频复刻音色，或者只用文字描述「温柔的少女音」。日常、开心、温柔三种情绪各自独立声线，开口即是「他、她、它」。

03

有状态作息

Agent 拥有当天的日程与当前活动：忙碌时消息进入待处理队列稍后回应，空闲时会更主动地找你。陪伴因此有了时间感。

04

长期记忆

聊过的话题、共同的经历、关系走到哪一步、最近的心情波动，都会成为后续交流的上下文。关系是延续的，不是每次从零开始。

05

动态人格表达

人格特征结合当前话题动态呈现，而不是机械复读口头禅。同一句话，在不同的关系阶段和情绪下，说出来都不一样。

06

隐私优先

配置、聊天、记忆全部存储在设备本地，API Key 加密保存；分享出去的 .agent.zip 不包含任何密钥与地址。

语音系统

让 Agent 开口说话
而且说得像真人

Ta 不只为 Agent 生成文字，还能为它合成专属声音。逐条合成、尊重标点断句、只读该读的文字。

音色复刻

上传一段参考音频，Ta 学习并复刻出接近这套音色的声音，让 Agent 拥有独一无二的声音。

参考音频 → 专属音色

音色设计

没有样本也没关系，直接用文字描述想要的音色，「清亮的少年音」「慵懒的低音」，由模型直接设计生成。

文字描述 → 设计音色

预置精品音色

不想折腾就直接挑一个内置精品音色，开箱即用。

即选即用

上手流程

四步开始你们的第一次对话

壹

准备模型服务

在「设置 → 模型服务」中填入 OpenAI 兼容接口的 Key 与地址。没有的话，各大模型平台都可以免费申请。

像朋友一样聊天。它会记住你们的故事，按自己的节奏生活，也在相处中慢慢变成独一无二的存在。
