# 定时任务提醒设置设计

## 目标

将“承诺定时提醒”合并到“定时任务”页面，设置页只保留一个始终可进入的“定时任务”入口。

## 交互

- “定时任务”不再受开发者模式控制，始终显示。
- 删除设置页独立的“承诺定时提醒”行。
- 定时任务页顶部显示提醒开关和简短说明。
- 开启说明：开启后，Agent 会在承诺到期时主动发消息提醒你。
- 关闭说明：关闭后不会到点主动发消息，Agent 会在后续对话中自然提醒。
- 无论开关状态，任务列表和历史记录均可查看。

## 调度

- 关闭时保存 `commitmentTimerEnabled=false`，并取消当前 Agent 全部 pending 任务 Alarm。
- 开启时保存 `commitmentTimerEnabled=true`，重新调度 triggerAt 位于未来的 pending 任务。
- 过期任务、无 triggerAt 任务和非 pending 任务不重新调度。
- 开关操作不修改任务状态，不删除任务。

## 验证

- 单元测试覆盖恢复调度过滤规则。
- 设置页始终出现单一“定时任务”入口。
- 定时任务页开关、说明和任务列表同时显示。
- 单元测试、Lint、Debug 构建和模拟器 UI 验证通过。
