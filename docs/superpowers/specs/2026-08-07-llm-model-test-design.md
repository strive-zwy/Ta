# LLM 模型测试设计

## 目标

在模型配置页的 LLM 卡片中增加与 TTS 测试按钮一致的测试入口，使用当前未保存的 Base URL、API Key 和 Model 向 OpenAI 兼容聊天接口发送 `hello`，验证模型能否正常回复。

## 行为

- 三个字段均非空时启用“测试模型”按钮。
- 点击后仅发送一条 `user: hello`，不携带 Agent Prompt、工具和聊天历史。
- 测试期间显示“正在测试…”，同时禁止重复测试。
- 成功弹窗展示模型返回文本和请求耗时。
- 空响应视为失败；网络、HTTP 和解析异常展示脱敏后的错误信息。
- 测试不写入聊天记录、记忆、关系、状态和模型配置。
- API Key 只用于本次请求，不写入 Preferences。

## 结构

- `LlmClient` 提供接收显式配置的诊断接口，绕开运行时激活模型配置。
- `ModelConfigScreen` 管理测试 loading 和结果状态，并复用现有诊断弹窗的视觉结构。
- 诊断结果使用独立数据类型，避免把聊天业务的 `AgentReply` 解析规则带入连接测试。

## 验证

- 单元测试覆盖字段清洗、空响应失败和成功结果格式。
- 编译、单元测试、Lint 和 Debug 构建通过。
- 模拟器中确认按钮状态、loading 和结果弹窗。
